
# Rockstar Games Hasher Bot

Uma ferramenta simples para gerar códigos de hash a partir de textos que você digita, direto no navegador.
Site: https://bresodev.github.io/HasherBot/

## O que faz?

O HasherBot pega qualquer texto que você escrever e calcula o código hash correspondente usando o algoritmo da Rockstar Games Rage Engine
 
## Como usar?

1. Abra o arquivo `index.html` no seu navegador.
2. Digite o texto que deseja transformar em hash.
3. Veja o resultado do código hash instantaneamente.

## Para quem é indicado?

- Desenvolvedores que precisam gerar hashes de listas ou palavras rapidamente.
- Estudantes e curiosos que querem entender como funciona hashing da Rockstar.
